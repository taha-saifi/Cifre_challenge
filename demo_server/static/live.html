Les formulations sont regroupées par similarité de Jaccard (seuil 0,80), le même mécanisme que le graphe figé. Une décision par groupe : accepter le fait entrer au graphe canonique, rejeter l'en exclure, laisser au système s'appuyer uniquement sur les garde-fous déjà codés. Un groupe laissé sans décision ne produit aucune arête.
