# CVE-2026-63520 — Disponibilité d'un correctif éditeur

## Conclusion

Oui, un correctif éditeur Microsoft est disponible pour CVE-2026-63520 : il est livré sous la forme de cinq mises à jour de sécurité identifiées par les références KB5002893, KB5002894, KB5002896, KB5002905 et KB5002906, chacune correspondant à une version précise de SharePoint.

## Justification

Le sous-graphe canonique contient cinq assertions explicites `has_patch` rattachées à CVE-2026-63520, toutes issues de la source S41, qui associent une référence KB à un produit et à une version cible :

| Référence KB | Produit concerné | Version corrigée |
|---|---|---|
| KB5002893 | Microsoft SharePoint Server Subscription Edition | 16.0.19725.20522 |
| KB5002894 | Microsoft SharePoint Server 2019 | 16.0.10417.20198 |
| KB5002896 | Microsoft SharePoint Server 2019 | 16.0.10417.20198 |
| KB5002905 | Microsoft SharePoint Enterprise Server 2016 | 16.0.5565.1001 |
| KB5002906 | Microsoft SharePoint Enterprise Server 2016 | 16.0.5565.1001 |

Éléments de corroboration présents dans le contexte :

- L'assertion `updates be_remediate CVE-2026-63520` (S41) confirme explicitement que ces mises à jour corrigent la vulnérabilité.
- La couverture des KB recouvre exactement les trois produits affectés déclarés par la source NVD S06 : SharePoint Enterprise Server 2016, SharePoint Server 2019 et SharePoint Server Subscription Edition. Aucun produit affecté ne reste sans correctif identifié.
- L'éditeur est bien à l'origine de la publication : la source de l'entrée est `secure@microsoft.com` (S06) et la référence officielle pointe vers le MSRC (`https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-63520`), ce qui qualifie ces KB comme correctifs éditeur et non comme contournements tiers.
- Le statut NVD est `Analyzed` et la date de dernière modification (2026-08-13) est postérieure à la publication (2026-08-11), cohérent avec un enrichissement post-publication des informations de remédiation.

## Réserves et points d'attention

- Deux KB distinctes sont associées à un même produit et à une même version corrigée (KB5002894 / KB5002896 pour SharePoint Server 2019, KB5002905 / KB5002906 pour SharePoint Enterprise Server 2016). Le contexte ne précise pas la nature de cette dualité : il s'agit typiquement de la séparation entre le paquet « core / language-independent » et le paquet applicatif, mais cette interprétation n'est pas confirmée par les données disponibles. En pratique, l'application des deux KB du couple doit être considérée comme nécessaire, à vérifier sur le bulletin MSRC.
- Le contexte ne fournit pas de date de publication des KB elles-mêmes, ni de mention d'un éventuel correctif pour d'autres éditions de SharePoint hors des trois produits listés.

## Contexte de risque associé (pour la priorisation du déploiement)

Le correctif est disponible et son application est à prioriser : score CVSS 3.1 de 8.1 (HIGH), vecteur `AV:N/AC:H/PR:N/UI:N/S:U/C:H/I:H/A:H` (exécution de code à distance, sans authentification ni interaction utilisateur), évaluation MSRC « Exploitation More Likely », probabilité EPSS de 2,89 % au 2026-08-28 pour un percentile de 85,9 %. Le contexte signale par ailleurs une possibilité de chaînage avec une vulnérabilité de contournement d'authentification, ainsi que la publication anticipée de détails techniques par Rapid7 — deux facteurs qui réduisent le délai d'apparition d'un exploit fonctionnel. À la date des données, ni exploitation active ni divulgation publique ne sont confirmées par le MSRC (`exploited: No`, `publicly disclosed: No`) et le SSVC `exploitation` est à `none`.
