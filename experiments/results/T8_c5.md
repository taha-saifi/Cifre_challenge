# T8_c5 — CVE-2026-63520 : un correctif éditeur est-il disponible, et sous quelle référence ?

## Conclusion

Les informations disponibles indiquent qu'une remédiation éditeur existe (Microsoft), mais **aucune référence précise de correctif (numéro de KB, build, ou numéro de mise à jour de sécurité) n'est présente dans le sous-graphe fourni** : il est donc impossible d'identifier la référence exacte du correctif à partir de ces seules données.

## Justification

**Ce qui est établi**

- La vulnérabilité est attribuée à Microsoft : `has_source_identifier secure@microsoft.com` [S06], et les produits affectés sont Microsoft SharePoint Enterprise Server 2016, SharePoint Server 2019 et SharePoint Server Subscription Edition [S06].
- Une remédiation est explicitement mentionnée : `updates be_remediate CVE-2026-63520` [S41]. Cette assertion indique que des mises à jour corrigent la vulnérabilité, mais elle est formulée de façon générique (« updates ») et ne porte aucun identifiant.
- Le statut NVD est `Analyzed` [S06], et la CVE dispose d'une référence à l'avis éditeur : `https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-63520` [S06]. Des métadonnées MSRC sont d'ailleurs présentes (`publicly_disclosed: No`, `exploited: No`, `exploitability_assessment: Exploitation More Likely` [S42]), ce qui confirme que l'avis MSRC a bien été traité — un avis MSRC de ce type s'accompagne normalement d'une mise à jour de sécurité.

**Ce qui manque**

- Aucun triplet du sous-graphe ne porte de référence de correctif : pas de numéro KB (type `KB50xxxxx`), pas de numéro de build, pas de date de patch, pas de relation du type « CVE → corrigée par → \<référence\> ». Le graphe est d'ailleurs signalé comme **incomplet**.
- La seule assertion de remédiation [S41] a un sujet non résolu (« updates »), ce qui est typique d'une extraction OpenIE dont l'antécédent réel (« the August 2026 security updates », « these updates », etc.) se trouvait dans une phrase précédente non capturée. On ne peut donc pas en déduire un identifiant.

**Conséquence pratique**

La détermination de la référence exacte du correctif suppose de consulter directement l'avis MSRC référencé en [S06] (`msrc.microsoft.com/update-guide/vulnerability/CVE-2026-63520`), qui liste les KB par produit affecté (SharePoint 2016, 2019, Subscription Edition — chacun ayant sa propre référence de mise à jour). Toute réponse citant un numéro de KB précis à partir des seules données ci-dessus serait une invention.

**Contexte de risque (pour la priorisation, indépendamment de la référence)** : score CVSS 3.1 de 8.1 (HIGH), vecteur réseau sans authentification ni interaction utilisateur (AV:N/PR:N/UI:N), EPSS à 0,0289 (percentile 0,86) au 2026-08-28, évaluation MSRC « Exploitation More Likely », et mention d'un chaînage possible avec une vulnérabilité de contournement d'authentification [S41] ainsi qu'avec CVE-2026-55040 menant à une RCE non authentifiée [S18]. La recherche de la référence exacte du correctif est donc à traiter en priorité.
