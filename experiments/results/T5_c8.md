# T5_c8 — CVE hors délai au regard de l'échéance CISA (date de référence : 2026-08-29)

## Conclusion

Quatre des cinq CVE du périmètre sont hors délai : **CVE-2026-33824, CVE-2026-55040, CVE-2026-59310 et CVE-2026-65400**, dont l'échéance d'action CISA était fixée au **2026-08-21**, soit **8 jours de retard** au 2026-08-29 ; **CVE-2026-63520** n'est pas concernée (aucune date d'échéance CISA dans les informations disponibles). L'obligation immédiate est donc de **remédier sans délai ces quatre vulnérabilités** (application des correctifs ou, à défaut, mise hors service / isolement des actifs affectés) et de **documenter le dépassement d'échéance**, la nature exacte de l'obligation réglementaire attachée à l'inscription au catalogue KEV ne pouvant toutefois pas être confirmée avec certitude à partir des sources disponibles.

### 2. Pourquoi CVE-2026-63520 est exclue

Le sous-graphe ne comporte pour CVE-2026-63520 **ni date d'ajout KEV, ni date d'échéance CISA, ni référence au catalogue KEV** (les quatre autres CVE portent chacune une référence `cisa.gov/known-exploited-vulnerabilities-catalog`). Son profil est cohérent avec cette absence : `SSVC_exploitation = none`, `SSVC_automatable = no`, `MSRC_exploited_status = No`, EPSS 0,029 (percentile 0,859), CVSS 8.1 HIGH avec complexité d'attaque élevée. Elle ne peut donc pas être déclarée « hors délai » : il n'existe aucune échéance à dépasser dans les informations disponibles. Cela ne signifie pas qu'elle est sans enjeu — elle est explicitement décrite comme chaînable avec le contournement d'authentification CVE-2026-55040 (S18, S41), ce qui en fait une priorité de correction propre, mais sur un autre fondement que l'échéance CISA.

### 3. Caractère aggravant du retard sur les quatre CVE concernées

Le dépassement porte sur des vulnérabilités toutes qualifiées d'**exploitation active** :

- `SSVC_exploitation = active`, `SSVC_automatable = yes`, `SSVC_technicalImpact = total` pour les quatre.
- Vecteurs réseau sans privilège ni interaction utilisateur (`AV:N/AC:L/PR:N/UI:N`), scores CVSS 9.8 / 9.1 / 9.8 / 9.8, exploitabilité maximale (3.9).
- Scores EPSS au 2026-08-28 élevés à très élevés : 0,727 (percentile 0,994) pour CVE-2026-33824 ; 0,459 (0,988) pour CVE-2026-59310 ; 0,397 (0,986) pour CVE-2026-55040 ; 0,099 (0,953) pour CVE-2026-65400.
- Preuves d'exploitation ou de disponibilité publique d'exploit : PoC Rapid7 publié pour CVE-2026-55040 et utilisé contre des honeypots SharePoint (S10, S18, S40) ; exploitation mondiale documentée pour CVE-2026-59310 (S04, S17) ; campagne référencée pour CVE-2026-33824 (S02, S45, S46).

Le retard porte donc sur le sous-ensemble le plus exposé du périmètre, pas sur des cas théoriques.

### 4. Obligation créée pour l'organisation

Sur la base des seules informations disponibles :

1. **Remédiation immédiate et prioritaire** des quatre CVE hors délai, l'échéance étant déjà dépassée : il n'y a plus de fenêtre de planification, seulement un retard à résorber.
2. **Voies de remédiation identifiées dans les sources** : correctifs Microsoft pour CVE-2026-33824 (S46) ; KB5002882 / KB5002883 / KB5002891 pour CVE-2026-55040 (S40) ; avis fournisseur VMSA-2026-0006 / Broadcom pour CVE-2026-59310 (S04, S12) ; correctifs Apple macOS Sequoia 15.7.9, Sonoma 14.8.9, Tahoe 26.6.1 pour CVE-2026-65400 (S05, S17). À défaut de pouvoir corriger, la mesure de repli usuelle est le retrait de service ou l'isolement réseau des actifs affectés jusqu'à correction.
3. **Vérification du périmètre d'exposition réel** : les produits affectés listés (parcs Windows 10/11 et Windows Server, SharePoint 2016/2019/Subscription Edition, vCenter / Cloud Foundation / vSphere Foundation / Telco Cloud, macOS) doivent être confrontés à l'inventaire des actifs pour déterminer quels systèmes sont concernés.
4. **Traçabilité du dépassement** : consigner la date d'échéance, la date de constat, l'état de correction et, le cas échéant, la justification du retard et les mesures compensatoires appliquées.
5. **Corriger également CVE-2026-63520 en parallèle**, non au titre de l'échéance CISA mais parce qu'elle se chaîne à CVE-2026-55040 ; les correctifs SharePoint sont disponibles (KB5002893 / KB5002894 / KB5002896 / KB5002905 / KB5002906, S41) et une source indique que corriger CVE-2026-55040 rompt la chaîne d'exploitation (S40).

### 5. Limite explicite

Les sources disponibles **ne permettent pas de confirmer la nature juridique exacte de l'obligation** attachée à l'inscription au catalogue KEV (champ d'application, entités assujetties, régime de dérogation, conséquences d'un dépassement). La conclusion ci-dessus établit donc un **constat factuel de dépassement d'échéance** et l'obligation opérationnelle qui en découle, sans se prononcer sur la qualification réglementaire. Cette question relève d'une validation par la direction / le référent conformité et ne doit pas être tranchée à partir de ce sous-graphe.
